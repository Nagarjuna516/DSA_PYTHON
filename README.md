# DSA Zero to Hero: 30-Day Bootcamp

A 30-day, 6-hours-a-day DSA study plan with YouTube lectures and practice problems.

Live site: https://YOUR-USERNAME.github.io/REPO-NAME/

## Files
- `index.html`: the complete website (upload this for the simplest setup)
- `build.py`: Python script that generates the same site (`python build.py --serve`)
- `.github/workflows/deploy.yml`: optional auto-deploy using GitHub Actions

## Publish
Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
